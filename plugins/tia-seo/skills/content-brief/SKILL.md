# Content Brief

A brief a writer can follow without asking questions. Base it on what currently ranks, not on guesses.

## Inputs

- The focus keyword (keep it exactly as written), the site URL, and the audience or country.
- If you can search the web, read the top 5 to 10 results for the keyword. If not, say the brief is built without live SERP data.

## Step 1: Read the results

For the top results note: page type (guide, list, tool, product), rough length, headings they share, questions they answer, and what none of them covers well. That gap is the angle.

## Step 2: Write the brief

```
Focus keyword:
Secondary keywords: (3-6 from the same cluster)
Search intent: (informational / commercial / transactional) + one line on what the searcher wants
Angle: what this page does better than the current results
Title (50-60 chars):
Meta description (140-160 chars):
Slug:
Target length: (based on the ranking pages, rounded; never pad)

Outline:
H1:
Intro: answer the main question in 2-3 sentences
H2 ...
  H3 ...
FAQ: 3-5 questions

Must include: facts, numbers, steps, examples or tools the page needs
Entities: people, products, places and terms a complete answer mentions
Internal links: anchor -> target URL (3-5)
External sources: official or primary sources to cite
Visuals: table, chart, screenshot or image ideas
```

## Rules

- Each H2 must earn its place: it answers something the searcher needs.
- Put a short, direct answer block near the top: it helps featured snippets and AI answers.
- Flag claims the writer must verify (prices, laws, dates, statistics).
- Keep it to one page. A brief is a plan, not the article.
