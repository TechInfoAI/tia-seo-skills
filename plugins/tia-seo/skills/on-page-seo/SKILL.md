# On-Page SEO

Return final values the user can paste, not advice. Keep the user's focus keyword exactly as written.

## Inputs

- The page URL or its text, and the focus keyword. Ask for the keyword if it is missing.
- Optional: 2 to 3 keywords from the same cluster, the site's other URLs for internal links.

## Checks and rules

| Element | Rule |
|---|---|
| Title tag | 50-60 characters. Focus keyword near the start. One reason to click (year, number, benefit). Unique on the site. |
| Meta description | 140-160 characters. Keyword once, natural. Says what the reader gets. Ends with a soft call to action. |
| URL slug | Short, lowercase, hyphens, keyword included, no dates or stop words unless needed. |
| H1 | One per page. Matches the topic of the title but need not copy it. |
| Intro | Answer the main question in the first 2-3 sentences, with the keyword in the first 100 words. |
| Headings | H2s cover the subtopics searchers expect; use real questions where it fits. No skipped levels. |
| Body | Matches search intent. Covers what the top results cover, plus one thing they miss. |
| Internal links | 3-5 links to related pages with descriptive anchors; 1-2 links from strong pages back to this one. |
| External links | 1-2 links to official or primary sources. |
| Images | Descriptive file names and alt text; keyword in one alt text only if it fits. |
| FAQ | 3-5 real questions from "People also ask" or the user's data, short direct answers. |

## Output

1. **Verdict**: one line on how well the page targets the keyword now.
2. **Ready-to-paste values**: title, meta description, slug, H1.
3. **Heading outline**: the full suggested H2/H3 list.
4. **Changes to the body**: what to add, cut or move, as short bullets.
5. **Internal links**: a table of anchor text and target URL.
6. **FAQ block**: questions and answers.

Never stuff the keyword. If the page's intent does not match the keyword (for example a product page for an informational query), say so first and suggest the right page type.
