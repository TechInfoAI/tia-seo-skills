# Link Building

Links from relevant, real sites still move rankings, and mentions on sites AI tools read help AI visibility. Quality and relevance matter more than count.

## Step 1: Choose tactics for the site

| Tactic | Works best for |
|---|---|
| Unlinked brand mentions | Brands that already get mentioned |
| Resource and "best tools" pages | Tools, guides, free resources |
| Guest posts on niche sites | Experts with something new to say |
| Link insertions into existing articles | A page that adds real value to an existing article |
| Broken link replacement | Sites in niches with old, dead resources |
| Digital PR and original data | Surveys, studies, free tools, tested comparisons |
| Directories and listings | Local businesses, SaaS and AI tools (only quality, niche ones) |

Pick 2 or 3 for the site; explain why in one line each.

## Step 2: Vet every site

A site is worth it when:
- It is in the same or a close niche, and its articles are written for readers.
- It has real organic traffic (from Ahrefs, Semrush or Similarweb if the user has them), and traffic is stable or growing.
- Its outbound links are not mostly casino, pharma, CBD or "write for us" spam.
- It is not a network of sites selling links on every page.
Red flags: traffic falling sharply, every post has a sponsored link, topics all over the place, spun content.

## Step 3: Outreach emails

Rules:
- Personal first line about something specific on their site.
- One clear, useful offer: a better resource, a fix for a broken link, an expert quote, a post idea list.
- Under 120 words. No attachments in the first email.
- One follow-up after 4-5 days, then stop.
- Disclose any payment as the site's own policy requires; follow Google's rules on paid links (rel="sponsored").

Write the email, a subject line under 50 characters, and a follow-up.

## Output

1. Tactic plan (2-3 tactics, why).
2. Prospect criteria and search operators to find sites, for example `"keyword" intitle:resources`, `"keyword" "write for us"`.
3. A vetting checklist the user can use on each site.
4. Outreach email + follow-up, personalized if a target site was given.
5. A simple tracker layout: site, contact, tactic, status, date sent, link live.

Never suggest PBNs, link schemes or spam comments.
